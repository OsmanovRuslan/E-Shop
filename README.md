# Курсовая работа "Интернет магазин"

## Суть проекта
Создать серверную часть (REST API) для интернет-магазина.</br>
Есть 3 вида пользователей (MANAGER, ADMIN, USER):</br>
<li>MANAGER может управлять товарами</li>
<li>ADMIN управляет всем, может удалять пользователей</li>
<li>USER может просматривать товары, добавлять к себе в корзину, делать заказ, и просматривать уведомления</li>

## Архитекутра проекта
Выбрана микросервисная архитектура.
Есть такие микросервисы:
<li>Auth</li> Для регистрации, авторизации и аутентификации пользователей.
<li>User</li> Для просмотра информации о пользователе, удаления, обновления и создания пользователя.
<li>Product</li> Для управления категориями товаров, товарами.
<li>Order</li> Для работы с корзиной товаров, подтверждения и отмены заказов.
<li>Notitfication</li> Для отправки email уведомлений о подтверждении и отмене заказов. Также есть наброски на уведомления внутри сайта.
 <li>Gateway</li> Для перенаправления запросов пользователей на разные сервисы.
<li>Eureka Server</li> Для хранения ифнормации о сервисах для Gateway.

## Межсервисные коммуникации
Все коммуникации выполнены через OpenFeign, кроме сообщений между Order и Notitfication сервисами, для них использользуетя Kafka.

## Авторизация и аутентификация
Авторизация и аутентификация выполняется через Keycloak. В базе данных User сервиса пароли пользователей не хранятся.
